# AI Film-Making Project

This project demonstrates a complete AI-powered film production pipeline using cutting-edge tools and technologies.

## Project Structure

```
ai-film-making/
├── 01-preproduction/          # Script, storyboards, planning
├── 02-production/             # Video generation, VFX
├── 03-postproduction/         # Editing, enhancement
├── assets/                    # Media files
│   ├── audio/                 # Voice, music, SFX
│   ├── video/                 # Generated video clips
│   └── images/                # Storyboards, concept art
└── docs/                      # Documentation and guides
```

## AI Tools Integration

| Tool | Stage | Purpose |
|------|-------|---------|
| GPT-4 | Pre-production | Script and story generation |
| Storyboarder.ai | Pre-production | Visual planning and animatics |
| OpenArt | Pre-production | Concept art and scene imagery |
| Runway ML | Production | Video generation and VFX |
| Luma Dream Machine | Production | High-quality video scenes |
| ElevenLabs | Production | AI voice generation |
| Descript | Post-production | Text-based video editing |
| Topaz Video AI | Post-production | Video enhancement and upscaling |

## Getting Started

1. **Clone the Repository**
   ```bash
   git clone <your-repository-url>
   cd ai-film-making
   ```

2. **Follow the Production Pipeline**
   - Review the script and storyboard in `01-preproduction/`
   - Follow the production workflow in `02-production/`
   - Complete post-production using files in `03-postproduction/`

3. **Contributing**
   - See [CONTRIBUTING.md](CONTRIBUTING.md) for Git workflow and PR guidelines
   - All changes must be made via Pull Requests to the `main` branch
   - Follow the established project structure and naming conventions

## Development Workflow

This project uses a **main branch workflow**:
- The `main` branch is protected and serves as the primary integration branch
- All feature development happens in feature branches
- Changes are merged to `main` only through reviewed Pull Requests
- Automated validation ensures code quality and project structure

For detailed contribution guidelines, see [CONTRIBUTING.md](CONTRIBUTING.md).
