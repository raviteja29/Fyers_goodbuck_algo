## 📝 Quick Project Setup (Day 1 - Afternoon)

### 1. Create Project Structure (5 minutes)
```
your-film-project/
├── 01-preproduction/
├── 02-production/
├── 03-postproduction/
├── assets/
│   ├── audio/
│   ├── video/
│   └── images/
└── final-output/
```

### 2. Generate Your Script (30 minutes)

**GPT-4 Prompt Template:**
```
Create a 3-5 minute short film script about [YOUR THEME]. 
Include:
- Clear 3-act structure
- 2-3 main characters
- Emotional core with universal themes
- Specific scene descriptions for AI video generation
- Technical notes for camera angles and lighting

Format as professional screenplay with scene headings, character names, and dialogue.
```

**Example themes to try:**
- A son of a wealthy man and a son of a poor man in 2 different incidents rape a woman and kill her, want poor fathers reaction and wealthy mans reaction.
-How do they react to a situation like this?
-what happens in a girls family life
-they ask death penalty to poor mans son and rich mans son
-when rich man offers money how do they change
-who is wrong, family?son?girls family?girl?society?
-instead of blaming every aspect having self consciousness should be the winner

## 🎨 Rapid Visual Development (Day 2)

### OpenArt Quick Setup:
1. **Create character references**
   - Generate 3-4 images per main character
   - Use consistent style prompts
   - Save all images with descriptive names

2. **Location concepts**
   - Generate 2-3 views of each location
   - Maintain consistent lighting/color palette
   - Create day/night variations if needed

**Quick Prompts:**
```
Character: "Professional portrait of [age] [ethnicity] [gender], [description], cinematic lighting, 4K"

Location: "[Location type], [lighting], [mood], wide shot, cinematic, detailed"
```

---

## 🎬 Speed Production (Days 3-4)

### Runway ML Fast Track:

**Text-to-Video (Simple scenes):**
1. Use your OpenArt images as references
2. Keep prompts under 500 characters
3. Generate 5-10 second clips maximum
4. Create 2-3 versions of important shots

**Quick Prompt Structure:**
```
[Character/location description], [camera angle], [lighting], cinematic, 24fps, high quality
```

### ElevenLabs Voice Generation:

**Character Voice Setup (30 minutes):**
1. **Select voices** matching your characters
2. **Test with sample dialogue** from script
3. **Generate all dialogue** scene by scene
4. **Create multiple takes** for key emotional moments

**Pro tip:** Generate voices in script order to maintain emotional continuity.

---

## ✂️ Quick Edit & Export (Days 5-6)

### Descript Fast Assembly:

**Day 5 - Assembly:**
1. **Import all video clips** organized by scene
2. **Import all audio files** with auto-transcription
3. **Sync video to audio** using text editing
4. **Trim and arrange** clips in story order

**Day 6 - Polish:**
1. **Add transitions** between scenes
2. **Basic color correction** (3 presets: warm/cool/neutral)
3. **Audio levels** balance
4. **Export 1080p version** for review

### Export Settings for Final:
```
Resolution: 1080p or 4K
Frame Rate: 24fps
Format: MP4
Quality: High (50+ Mbps)
Audio: 48kHz stereo
```

## 💡 Quick Tips for Success

### Script Writing:
- **Keep it simple** for first project
- **Write visually** - describe what we see
- **Limit locations** to 2-3 maximum
- **Focus on emotion** over complex plot

### Video Generation:
- **Start with wide shots** (easier to generate)
- **Generate extra coverage** (you'll need options)
- **Keep characters consistent** with reference images
- **Break complex scenes** into simple shots

### Audio Production:
- **Record clean dialogue first** before adding effects
- **Generate multiple takes** of emotional moments
- **Keep background audio simple**
- **Test voices early** to ensure they fit characters

### Editing:
- **Edit for emotion** not just story
- **Use simple transitions** (cuts and fades)
- **Keep music subtle** - dialogue is key
- **Review frequently** on different devices

## 🆘 Common First-Time Issues

### "My characters don't look consistent"
**Solution:** Use the same reference image and seed numbers in Runway ML

### "The dialogue sounds robotic"
**Solution:** Adjust ElevenLabs stability (try 0.75) and regenerate

### "Video clips are too short"
**Solution:** Generate multiple angles of the same scene, edit together

### "Audio and video don't sync"
**Solution:** Use Descript's automatic sync feature, then fine-tune manually
