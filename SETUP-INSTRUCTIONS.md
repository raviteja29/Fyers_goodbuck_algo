# Setup Instructions (Frontend + Backend)

See `FULLSTACK-SETUP.md` for combined steps; this file focuses on quick start.

1. Copy `.env.example` to `.env` and fill values.
2. Install dependencies: `npm install` (root) and `npm install` in `server/`.
3. Run both: `npm run dev:all` (after updating root package.json script).
4. Open http://localhost:5173.
